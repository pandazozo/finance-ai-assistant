## 二、功能需求

### 2.1 P0：LLM接入

#### 2.1.1 功能描述

将AI结论生成从规则引擎升级为LLM驱动，提供更自然、可解释的个性化结论。

#### 2.1.2 验收标准（AC）

| AC ID | 验收标准 | 测试方法 |
|--------|----------|----------|
| **AC-P2-1.1** | LLM可用时，AI结论使用自然语言生成 | API返回LLM生成的文本 |
| **AC-P2-1.2** | LLM不可用时，降级到规则引擎 | API返回规则引擎结果 |
| **AC-P2-1.3** | LLM结论包含风险偏好因素 | 不同风险偏好生成不同措辞 |
| **AC-P2-1.4** | 响应时间<3秒 | API响应时间监控 |
| **AC-P2-1.5** | 生成失败有友好提示 | 降级说明展示 |

#### 2.1.3 技术方案

**LLM选型**：阿里通义千问（成本可控，中文理解好）

**Prompt设计**：
```
你是一位专业的A股分析师。用户正在查看{stock_name}({stock_code})的股票详情。

当前行情数据：
- 最新价：{price}元
- 涨跌幅：{change}%
- 成交量：{volume}万手

用户风险偏好：{risk_preference_label}
- 高风险偏好：进取型
- 中风险偏好：均衡型
- 低风险偏好：稳健型

请生成一段简洁的分析结论（100字以内），要求：
1. 结合行情数据和风险偏好
2. 使用专业但易懂的语言
3. 包含投资建议
4. 结尾必须包含免责声明

风险提示：市场有风险，投资需谨慎。AI分析仅供参考，不构成投资建议。
```

**降级策略**：
```
LLM不可用 → 规则引擎
↓
显示提示："当前使用规则分析，AI深度分析即将上线"
```

### 2.2 P1：资讯权重算法

#### 2.2.1 功能描述

引入资讯权重计算，量化新闻/情报对股价的影响程度。

#### 2.2.2 验收标准（AC）

| AC ID | 验收标准 | 测试方法 |
|--------|----------|----------|
| **AC-P2-2.1** | 显示相关资讯列表 | 股票详情页展示关联新闻 |
| **AC-P2-2.2** | 资讯有影响力评分 | 评分0-100显示 |
| **AC-P2-2.3** | 高权重资讯突出显示 | 标记为"重要"或颜色区分 |
| **AC-P2-2.4** | 支持手动刷新资讯 | 下拉刷新获取最新 |

#### 2.2.3 技术方案

**资讯来源**：AKShare财经新闻API

**权重计算公式**：
```
影响力评分 = Σ(因子权重 × 因子得分)

因子权重：
- 时效性(30%)：发布时间越近得分越高
- 相关性(40%)：资讯提及股票次数/密度
- 来源权威性(30%)：官方媒体>财经媒体>自媒体

权重范围：0-100
```

## 三、非功能需求

### 3.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| LLM响应时间 | <3秒 | 含降级处理 |
| API响应时间 | <1秒 | 非LLM接口 |
| 前端加载时间 | <2秒 | 首屏加载 |

### 3.2 可用性要求

| 场景 | 处理方式 |
|------|----------|
| LLM服务不可用 | 降级到规则引擎 + 友好提示 |
| 数据源不可用 | 展示缓存数据 + 提示更新时间 |
| 网络异常 | 展示错误提示 + 重试按钮 |

### 3.3 安全要求

| 要求 | 实现 |
|------|------|
| API Key安全 | 使用环境变量，不硬编码 |
| 敏感信息 | 不在日志中打印 |
| 输入验证 | 所有用户输入验证 |

## 四、数据流设计

### 4.1 LLM结论生成流程

```
用户请求 → 后端API → 检查LLM可用性
                    ↓
         LLM可用 → 调用LLM API → 格式化Prompt → 解析响应 → 返回
                    ↓
         LLM不可用 → 规则引擎 → 生成结论 → 返回
                    ↓
              统一响应格式
```

### 4.2 资讯权重计算流程

```
获取股票资讯 → 时效性评分 → 相关性评分 → 权威性评分
                                        ↓
                              权重汇总 → 排序展示
```

```json
{
  "code": "600519",
  "limit": 10
}
```

```json
{

  "data": {
    "news": [
      {

        "source": "上证报",
        "time": "2026-05-12 10:00",

  }
```

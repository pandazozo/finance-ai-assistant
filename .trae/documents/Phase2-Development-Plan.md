## 四、部署计划

### 4.1 Railway部署

```bash
# 1. 更新requirements.txt
echo "dashscope" >> requirements.txt

# 2. 设置环境变量
railway variables set DASHSCOPE_API_KEY=$DASHSCOPE_API_KEY

# 3. 部署
git add . && git commit -m "Phase 2.1 LLM接入" && git push
```

### 4.2 回滚方案

如果Phase 2部署失败：
1. Railway一键回滚到Phase 1版本
2. 保留Phase 2代码在main分支，待修复后重新部署

## 四、Bug记录

### BUG-001：搜索接口URL编码问题

| 字段 | 内容 |
|------|------|
| **Bug ID** | BUG-001 |
| **用例ID** | TC-005 |
| **严重程度** | P1 |
| **发现日期** | 2026-05-12 |
| **问题描述** | 搜索接口无法处理URL编码的中文参数，返回400错误 |
| **复现步骤** | 1. 打开App 2. 点击"+" 3. 输入"茅台"搜索 |
| **预期结果** | 返回搜索结果列表 |
| **实际结果** | 返回400 Bad Request |
| **根因** | server.py中搜索接口直接使用原始路径，未解析URL编码 |
| **修复方案** | 使用urllib.parse的parse_qs和unquote解析参数 |
| **修复版本** | de81bf6 |
| **验证日期** | 2026-05-12 |
| **验证结果** | ✅ 已修复，验证通过 |

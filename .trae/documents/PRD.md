## 一、产品概述

### 1.1 产品愿景

**产品slogan**：AI驱动的智能选股决策前置工具

**一句话描述**：
> 帮有经验的散户和专业交易者，从海量信息中快速发现投资机会，给出「买/卖/关注」的决策建议，让他们直接跳转券商软件操作。

**核心定位**：
- **不是**：替代券商交易软件
- **而是**：决策前置工具 - 帮用户「发现机会」，然后跳转券商软件「执行操作」

## 二、市场调研与竞品分析

### 2.1 竞品概览

| 产品 | 定位 | 核心亮点 | 不足 |
|------|------|----------|------|
| **同花顺问财** | 智能选股+量化分析 | 自然语言选股、形态选股、10年历史数据 | 千篇一律、缺乏个性化 |
| **东方财富妙想** | 全场景投资助手 | 对话体验好、财报解读、基金联动 | 选股效率不如问财直接 |
| **AI涨乐（华泰）** | AI原生交易APP | 7*24小时盯盘、双驱动交互（GUI+LUI）、事件传导 | 依赖券商账户、合规约束 |
| **股灵智选** | 题材数据挖掘 | 全题材覆盖、涨停分析、K线策略 | 功能堆砌、缺AI判断 |
| **且慢AI小顾** | 基金智能投顾 | 30+专家Agent、MCP工具、千人千策 | 仅限基金、非股票 |

### 2.2 调研核心发现

#### ✅ 值得借鉴的设计

1. **且慢的「AI专家团」模式**
   - 1个总指挥Agent + 30+细分领域Agent
   - 每个Agent专注一个领域，专业度高
   - 可解释性强：「规划→工具调用→数据→结论」全链路展示

2. **AI涨乐的「盯盘套餐」设计**
   - 预设多种盯盘模式（主力动向、阶段趋势、重大风险等）
   - 支持自然语言自定义盯盘需求
   - 触发后锁屏推送 + 逻辑解读

3. **同花顺问财的「一句话选股」**
   - 自然语言 → 结构化筛选条件
   - 技术面+基本面+资金面全覆盖
   - 形态选股（突破新高、W底等）

4. **蚂蚁财富AI智投的「风险偏好」**
   - 5分钟问卷 → 生成专属方案
   - 「60%指数基金+30%债券+10%货币」的资产配置建议
   - 动态调整 + 定期提醒

#### ❌ 需要避免的坑

1. **同质化严重**
   - 大多数产品选股逻辑雷同
   - 缺乏「个性化」和「差异化判断」

2. **信息过载**
   - 股灵智选等功能堆砌，新手上手难
   - 应该渐进式展示，不要一上来就给所有数据

3. **合规约束**
   - 券商系产品受监管限制，不能直接「荐股」
   - 我们定位「参考决策工具」，合规压力小

### 2.3 我们的差异化机会

| 差异化维度 | 竞品现状 | 我们的机会 |
|------------|----------|------------|
| **自定义策略** | 大多是固定规则 | 让用户配置自己的规则和权重 |
| **资讯聚合** | 依赖官方数据源 | 聚合KOL/公众号/社区热帖 |
| **AI Agent** | 单Agent为主 | 多Agent协作，深度个性化 |
| **风险偏好** | 抽象等级 | 落实为「资金配置比例」 |
| **决策输出** | 数据罗列 | 直接给「买/卖/关注」结论 |

## 三、目标用户

### 3.1 核心用户画像

#### 用户A：有一定经验的散户
- **特征**：炒了2-5年股，了解基本概念，但缺乏系统方法
- **痛点**：信息太多，不知道信谁；选股全靠感觉
- **需求**：有个「聪明助手」帮他筛选、给出建议
- **行为**：手机看资讯为主，频繁查看涨跌

#### 用户B：专业交易者
- **特征**：有自己的一套交易系统，关注短线和热点
- **痛点**：盯盘太累，热点切换快容易错过
- **需求**：高效发现机会 + 自定义盯盘规则
- **行为**：多屏切换，需要快速决策工具

### 3.2 用户核心诉求

| 优先级 | 诉求 | 痛点 |
|--------|------|------|
| P0 | 快速发现机会 | 信息太多太杂，人工筛选效率低 |
| P0 | AI给出判断 | 不知道该不该买，想听「专家意见」 |
| P0 | 跳转到交易软件 | 在我们这看完，还得去券商APP操作 |
| P1 | 自定义配置 | 每个人的关注点不同，想要「个性化」 |
| P1 | 盘前/盘后闭环 | 开盘前不知道关注什么，收盘后不知道复盘什么 |
| P2 | 资讯聚合 | 不用在多个APP之间切换 |

## 五、AI决策体系设计

### 5.1 风险偏好模型

#### 传统 vs 我们的定义

| 类型 | 传统定义 | 我们的定义 |
|------|----------|------------|
| **风险偏好** | 抽象等级（保守/稳健/激进） | **资金配置比例** |
| **适用用户** | 小白 | 有经验的专业用户 |

#### 我们的风险偏好模型

```
风险偏好 = 用户资金的「风险标的配置比例」

配置维度：
┌────────────────────────────────────────────────────────────┐
│  高风险层（涨停板、题材股、龙头股等）   │ 默认40% │ 可调整 │
│  中风险层（优质成长股、指数基金等）     │ 默认35% │ 可调整 │
│  低风险层（蓝筹股、债券、现金等）       │ 默认25% │ 可调整 │
└────────────────────────────────────────────────────────────┘
```

#### 获取方式

**Phase 1（初始版本）**：
1. 系统给出「中等风险」默认值（40/35/25）
2. 用户可通过问卷快速调整
3. 用户可精细化自定义每层比例

**问卷设计（简化版，5题）**：
```
1. 你能接受单日最大亏损多少？
   A. 5%以内  B. 10%以内  C. 20%以内  D. 30%以上

2. 你的投资周期通常是？
   A. 隔日超短  B. 1周内  C. 1个月内  D. 1个月以上

3. 你更倾向于？
   A. 少量高收益  B. 稳定增值  C. 均衡型

4. 你有多少资金用于股票投资？
   A. <10万  B. 10-50万  C. 50万以上

5. 这笔钱多久不用？
   A. 随时要用  B. 3个月内不用  C. 半年以上不用
```

**长期规划（Phase 2+）**：
- 基于用户实际行为学习（点击、关注、买卖记录）
- 动态调整风险偏好建议

### 5.2 AI判断档位设计

#### 10档判断（5档正负）

```
强烈推荐(+5) → 推荐(+3) → 谨慎推荐(+1) → 中性(0) → 谨慎观望(-1) → 回避(+3) → 强烈回避(+5)
```

#### 与风险偏好的关联

| 风险偏好 | 同一只股票的可能判断 |
|----------|---------------------|
| 激进型 | 强烈推荐 |
| 均衡型 | 推荐 |
| 保守型 | 中性 |

**计算逻辑**：
```
最终评分 = Σ(因子得分 × 权重) × 风险偏好系数

风险偏好系数：
- 激进型(偏好高风险)：系数 > 1，放大正向信号
- 均衡型：系数 = 1
- 保守型：系数 < 1，放大风险信号
```

---

### 5.3 资讯权重算法

#### 两个维度的权重

| 维度 | 说明 | 配置粒度 |
|------|------|---------|
| **来源权重** | 不同来源的可信度 | 每个来源单独配置 |
| **类型权重** | 不同类型资讯的信号强度 | 预设 + 可调整 |

#### 来源权重配置

```
资讯来源类型：
┌────────────────────────────────────────────────────────────┐
│  来源类型          │  默认权重  │  用户可配置  │
├────────────────────────────────────────────────────────────┤
│  机构研报          │    0.9    │     ✅       │
│  财经新闻（权威）  │    0.8    │     ✅       │
│  KOL/大V（粉丝多） │    0.7    │     ✅       │
│  社区热帖          │    0.5    │     ✅       │
│  公众号            │    0.6    │     ✅       │
└────────────────────────────────────────────────────────────┘
```

#### 类型权重配置

```
资讯类型：
┌────────────────────────────────────────────────────────────┐
│  类型              │  信号方向  │  默认权重  │  说明      │
├────────────────────────────────────────────────────────────┤
│  业绩预告/公告     │    正向    │    0.9    │  最权威    │
│  政策利好          │    正向    │    0.85   │  影响大    │
│  研报上调评级      │    正向    │    0.8    │  机构背书  │
│  龙头股涨停        │    正向    │    0.75   │  板块联动  │
│  技术突破          │    正向    │    0.6    │  参考信号  │
├────────────────────────────────────────────────────────────┤
│  业绩暴雷          │    负向    │    0.9    │  风险信号  │
│  监管问询          │    负向    │    0.8    │  风险信号  │
│  大股东减持        │    负向    │    0.75   │  负面信号  │
│  技术破位          │    负向    │    0.6    │  参考信号  │
└────────────────────────────────────────────────────────────┘
```

#### 综合评分公式

```
股票AI评分 = Σ(来源权重 × 类型权重 × 资讯情感值) / Σ来源权重 + 技术面得分 × 0.4 + 资金面得分 × 0.3

说明：
- 资讯情感值：正向=+1，负向=-1
- 技术面得分：基于价格形态、均线等（0-100分）
- 资金面得分：基于成交量、资金流向等（0-100分）
- 最终得分映射到10档判断
```

### 7.2 数据源规划

| 数据类型 | 数据源 | 优先级 | 说明 |
|---------|--------|--------|------|

| 资讯数据 | 自建爬虫 | P0 | 财经新闻、公告 |

## 八、产品路线图

### Phase 1（MVP，4-6周）

**目标**：验证核心价值 - 「AI给出判断 + 渐进式展示」

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 盘前热点推荐 | 每天生成5-10个热点主题 | P0 |
| 异动情报 | 涨跌幅异动监控 | P0 |
| 个股详情 | 三层信息架构（AI结论+信号+资讯） | P0 |
| 风险偏好 | 问卷 + 默认配置 | P0 |
| 资讯来源配置 | 预设来源 + 权重开关 | P1 |
| 跳转交易 | 外部链接跳券商APP | P1 |
| 自选股管理 | 添加/删除/分组 | P1 |
| 智能复盘 | 每日复盘 + 次日建议 | P2 |

### Phase 2（增强，2-3月）

**目标**：强化「个性化」和「自定义」

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 关注板块配置 | 自定义关注的行业/概念板块 | P0 |
| KOL订阅 | 关注特定大V，优先展示其观点 | P0 |
| 异动规则自定义 | 自然语言设置盯盘条件 | P0 |
| 资讯权重精细化 | 每个来源单独调整权重 | P1 |
| 风险偏好动态学习 | 基于行为调整偏好建议 | P2 |
| 推送通知 | 应用内+红点（暂不推送到手机） | P2 |

### Phase 3（高级功能，3-6月）

**目标**：构建「自定义策略」护城河

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 自定义规则引擎 | IF-THEN规则配置 | P0 |
| 策略回测 | 历史数据验证自定义策略 | P1 |
| 社群热帖聚合 | 筛选高质量社区内容 | P1 |
| 多券商交易跳转 | 支持多家券商APP | P2 |
| 运营后台 | 内容运营、推送管理 | P2 |

## 一、产品概述

### 1.1 产品愿景

**产品slogan**：AI驱动的智能选股决策前置工具

**一句话描述**：
> 帮有经验的散户和专业交易者，从海量信息中快速发现投资机会，给出「买/卖/关注」的决策建议，让他们直接跳转券商软件操作。

**核心定位**：
- **不是**：替代券商交易软件
- **而是**：决策前置工具 - 帮用户「发现机会」，然后跳转券商软件「执行操作」

## 二、市场调研与竞品分析

### 2.1 竞品概览

| 产品 | 定位 | 核心亮点 | 不足 |
|------|------|----------|------|
| **同花顺问财** | 智能选股+量化分析 | 自然语言选股、形态选股、10年历史数据 | 千篇一律、缺乏个性化 |
| **东方财富妙想** | 全场景投资助手 | 对话体验好、财报解读、基金联动 | 选股效率不如问财直接 |
| **AI涨乐（华泰）** | AI原生交易APP | 7*24小时盯盘、双驱动交互（GUI+LUI）、事件传导 | 依赖券商账户、合规约束 |
| **股灵智选** | 题材数据挖掘 | 全题材覆盖、涨停分析、K线策略 | 功能堆砌、缺AI判断 |
| **且慢AI小顾** | 基金智能投顾 | 30+专家Agent、MCP工具、千人千策 | 仅限基金、非股票 |

### 2.2 调研核心发现

#### ✅ 值得借鉴的设计

1. **且慢的「AI专家团」模式**
   - 1个总指挥Agent + 30+细分领域Agent
   - 每个Agent专注一个领域，专业度高
   - 可解释性强：「规划→工具调用→数据→结论」全链路展示

2. **AI涨乐的「盯盘套餐」设计**
   - 预设多种盯盘模式（主力动向、阶段趋势、重大风险等）
   - 支持自然语言自定义盯盘需求
   - 触发后锁屏推送 + 逻辑解读

3. **同花顺问财的「一句话选股」**
   - 自然语言 → 结构化筛选条件
   - 技术面+基本面+资金面全覆盖
   - 形态选股（突破新高、W底等）

4. **蚂蚁财富AI智投的「风险偏好」**
   - 5分钟问卷 → 生成专属方案
   - 「60%指数基金+30%债券+10%货币」的资产配置建议
   - 动态调整 + 定期提醒

#### ❌ 需要避免的坑

1. **同质化严重**
   - 大多数产品选股逻辑雷同
   - 缺乏「个性化」和「差异化判断」

2. **信息过载**
   - 股灵智选等功能堆砌，新手上手难
   - 应该渐进式展示，不要一上来就给所有数据

3. **合规约束**
   - 券商系产品受监管限制，不能直接「荐股」
   - 我们定位「参考决策工具」，合规压力小

### 2.3 我们的差异化机会

| 差异化维度 | 竞品现状 | 我们的机会 |
|------------|----------|------------|
| **自定义策略** | 大多是固定规则 | 让用户配置自己的规则和权重 |
| **资讯聚合** | 依赖官方数据源 | 聚合KOL/公众号/社区热帖 |
| **AI Agent** | 单Agent为主 | 多Agent协作，深度个性化 |
| **风险偏好** | 抽象等级 | 落实为「资金配置比例」 |
| **决策输出** | 数据罗列 | 直接给「买/卖/关注」结论 |

## 三、目标用户

### 3.1 核心用户画像

#### 用户A：有一定经验的散户
- **特征**：炒了2-5年股，了解基本概念，但缺乏系统方法
- **痛点**：信息太多，不知道信谁；选股全靠感觉
- **需求**：有个「聪明助手」帮他筛选、给出建议
- **行为**：手机看资讯为主，频繁查看涨跌

#### 用户B：专业交易者
- **特征**：有自己的一套交易系统，关注短线和热点
- **痛点**：盯盘太累，热点切换快容易错过
- **需求**：高效发现机会 + 自定义盯盘规则
- **行为**：多屏切换，需要快速决策工具

### 3.2 用户核心诉求

| 优先级 | 诉求 | 痛点 |
|--------|------|------|
| P0 | 快速发现机会 | 信息太多太杂，人工筛选效率低 |
| P0 | AI给出判断 | 不知道该不该买，想听「专家意见」 |
| P0 | 跳转到交易软件 | 在我们这看完，还得去券商APP操作 |
| P1 | 自定义配置 | 每个人的关注点不同，想要「个性化」 |
| P1 | 盘前/盘后闭环 | 开盘前不知道关注什么，收盘后不知道复盘什么 |
| P2 | 资讯聚合 | 不用在多个APP之间切换 |

## 五、AI决策体系设计

### 5.1 风险偏好模型

#### 传统 vs 我们的定义

| 类型 | 传统定义 | 我们的定义 |
|------|----------|------------|
| **风险偏好** | 抽象等级（保守/稳健/激进） | **资金配置比例** |
| **适用用户** | 小白 | 有经验的专业用户 |

#### 我们的风险偏好模型

```
风险偏好 = 用户资金的「风险标的配置比例」

配置维度：
┌────────────────────────────────────────────────────────────┐
│  高风险层（涨停板、题材股、龙头股等）   │ 默认40% │ 可调整 │
│  中风险层（优质成长股、指数基金等）     │ 默认35% │ 可调整 │
│  低风险层（蓝筹股、债券、现金等）       │ 默认25% │ 可调整 │
└────────────────────────────────────────────────────────────┘
```

#### 获取方式

**Phase 1（初始版本）**：
1. 系统给出「中等风险」默认值（40/35/25）
2. 用户可通过问卷快速调整
3. 用户可精细化自定义每层比例

**问卷设计（简化版，5题）**：
```
1. 你能接受单日最大亏损多少？
   A. 5%以内  B. 10%以内  C. 20%以内  D. 30%以上

2. 你的投资周期通常是？
   A. 隔日超短  B. 1周内  C. 1个月内  D. 1个月以上

3. 你更倾向于？
   A. 少量高收益  B. 稳定增值  C. 均衡型

4. 你有多少资金用于股票投资？
   A. <10万  B. 10-50万  C. 50万以上

5. 这笔钱多久不用？
   A. 随时要用  B. 3个月内不用  C. 半年以上不用
```

**长期规划（Phase 2+）**：
- 基于用户实际行为学习（点击、关注、买卖记录）
- 动态调整风险偏好建议

### 5.2 AI判断档位设计

#### 10档判断（5档正负）

```
强烈推荐(+5) → 推荐(+3) → 谨慎推荐(+1) → 中性(0) → 谨慎观望(-1) → 回避(+3) → 强烈回避(+5)
```

#### 与风险偏好的关联

| 风险偏好 | 同一只股票的可能判断 |
|----------|---------------------|
| 激进型 | 强烈推荐 |
| 均衡型 | 推荐 |
| 保守型 | 中性 |

**计算逻辑**：
```
最终评分 = Σ(因子得分 × 权重) × 风险偏好系数

风险偏好系数：
- 激进型(偏好高风险)：系数 > 1，放大正向信号
- 均衡型：系数 = 1
- 保守型：系数 < 1，放大风险信号
```

---

### 5.3 资讯权重算法

#### 两个维度的权重

| 维度 | 说明 | 配置粒度 |
|------|------|---------|
| **来源权重** | 不同来源的可信度 | 每个来源单独配置 |
| **类型权重** | 不同类型资讯的信号强度 | 预设 + 可调整 |

#### 来源权重配置

```
资讯来源类型：
┌────────────────────────────────────────────────────────────┐
│  来源类型          │  默认权重  │  用户可配置  │
├────────────────────────────────────────────────────────────┤
│  机构研报          │    0.9    │     ✅       │
│  财经新闻（权威）  │    0.8    │     ✅       │
│  KOL/大V（粉丝多） │    0.7    │     ✅       │
│  社区热帖          │    0.5    │     ✅       │
│  公众号            │    0.6    │     ✅       │
└────────────────────────────────────────────────────────────┘
```

#### 类型权重配置

```
资讯类型：
┌────────────────────────────────────────────────────────────┐
│  类型              │  信号方向  │  默认权重  │  说明      │
├────────────────────────────────────────────────────────────┤
│  业绩预告/公告     │    正向    │    0.9    │  最权威    │
│  政策利好          │    正向    │    0.85   │  影响大    │
│  研报上调评级      │    正向    │    0.8    │  机构背书  │
│  龙头股涨停        │    正向    │    0.75   │  板块联动  │
│  技术突破          │    正向    │    0.6    │  参考信号  │
├────────────────────────────────────────────────────────────┤
│  业绩暴雷          │    负向    │    0.9    │  风险信号  │
│  监管问询          │    负向    │    0.8    │  风险信号  │
│  大股东减持        │    负向    │    0.75   │  负面信号  │
│  技术破位          │    负向    │    0.6    │  参考信号  │
└────────────────────────────────────────────────────────────┘
```

#### 综合评分公式

```
股票AI评分 = Σ(来源权重 × 类型权重 × 资讯情感值) / Σ来源权重 + 技术面得分 × 0.4 + 资金面得分 × 0.3

说明：
- 资讯情感值：正向=+1，负向=-1
- 技术面得分：基于价格形态、均线等（0-100分）
- 资金面得分：基于成交量、资金流向等（0-100分）
- 最终得分映射到10档判断
```

### 11.1 数据收集原则

| 原则 | 说明 |

| **最小必要** | 只收集实现功能所必需的数据 |

| **用户控制** | 用户可查看、导出、删除自己的数据 |
| **安全保障** | 加密存储，定期审计，不泄露给第三方 |

## 十二、合规声明与内容处理方案

### 12.1 产品定性声明

**产品定位**：投资决策参考工具（非投资顾问）

| 声明要点 | 内容 |
|----------|------|
| **产品性质** | 信息聚合 + AI分析工具，非投资顾问服务 |
| **服务关系** | 不与用户建立委托理财关系 |
| **法律定性** | 不构成《证券法》意义上的投资咨询 |
| **风险提示** | 所有内容仅供「参考」，投资风险自负 |

**法律依据**：
- 《证券法》第160条：投资咨询机构需取得许可证
- 本产品定位为「信息展示」，不提供具体买卖建议
- AI生成的结论定性为「机器分析结果」，非人工投资建议

### 12.2 内容来源合规处理

#### 12.2.1 自建内容（原创）

| 内容类型 | 合规处理 | 展示要求 |
|----------|----------|----------|
| 行情数据 | 注明数据来源（新浪/东财/同花顺） | 「数据来源：XXX，仅供参考」 |
| 资讯摘要 | AI改写，保留核心信息 | 「资讯来源：XXX，摘要整理」 |
| AI结论 | 基于公开数据的机器分析 | 「本结论由AI自动生成，仅供参考」 |

#### 12.2.2 第三方内容（聚合）

| 来源类型 | 合规处理 | 展示要求 |
|----------|----------|----------|
| **财经新闻** | 全文展示，保留原文链接 | 标注来源媒体，保留原始链接 |
| **KOL观点** | 原文转发，注明作者 | 显示作者名称、粉丝数、发布时间 |
| **公众号文章** | 摘要+链接，不做内容篡改 | 「本文来自公众号：XXX」 |
| **社区帖子** | 用户生成内容（UGC）标识 | 「股吧用户@XXX观点，仅供参考」 |

#### 12.2.3 禁止展示内容

```
┌────────────────────────────────────────────────────────────┐
│                      禁止展示清单                           │
├────────────────────────────────────────────────────────────┤
│  ❌ 具体买卖价格建议                                        │
│  ❌ 「明天涨停板」「必涨XX%」等确定性表述                    │
│  ❌ 模拟/虚假收益率展示                                     │
│  ❌ 未经授权的机构研报全文                                  │
│  ❌ 内幕消息、非公开信息                                    │
└────────────────────────────────────────────────────────────┘
```

### 12.3 免责声明体系

#### 12.3.1 全局免责声明

**底部常驻声明**：
```
┌────────────────────────────────────────────────────────────┐
│  ⚠️ 免责声明                                                │
```

| 审核环节 | 处理方式 | 时效要求 |

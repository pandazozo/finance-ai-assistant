## 一、Phase 3 产品目标

### 1.1 核心目标

在Phase 2基础上，构建「自定义策略」护城河，让用户可以创建、回测自己的选股策略。

| 目标 | 优先级 | 说明 |
|------|--------|------|
| 自定义规则引擎 | P0 | IF-THEN规则配置，用户定义选股条件 |
| 策略回测 | P1 | 用历史数据验证自定义策略 |
| 社群热帖聚合 | P1 | 筛选高质量社区内容（股吧、雪球等） |
| 多券商交易跳转 | P2 | 支持多家主流券商APP |

### 1.2 核心价值提升

| 阶段 | 能力 | 体验 |
|------|------|------|
| Phase 1-2 | AI给结论，用户看结论 | 单向输出，用户只能接受 |
| **Phase 3** | **用户定义规则，AI帮回测** | **双向互动，用户主导** |

## 二、功能需求

### 2.1 P0：自定义规则引擎

#### 2.1.1 功能描述

提供可视化IF-THEN规则编辑器，让用户创建自己的选股策略。

#### 2.1.2 验收标准（AC）

| AC ID | 验收条件 | 测试方法 |
|-------|----------|----------|
| **AC-P3-1.1** | 支持「技术面」条件配置 | 可配置「涨跌幅>3%」「成交量放大1.5倍」 |
| **AC-P3-1.2** | 支持「基本面」条件配置 | 可配置「市盈率<30」「营收同比增长>20%」 |
| **AC-P3-1.3** | 支持「消息面」条件配置 | 可配置「有利好公告」「权威媒体报道」 |
| **AC-P3-1.4** | 支持多个条件「AND/OR」组合 | 可配置「涨跌幅>3% AND 成交量放大 AND 市盈率<30」 |
| **AC-P3-1.5** | 规则实时生效，匹配的股票显示在「策略池」 | 创建规则后，满足条件的股票自动出现在策略池 |
| **AC-P3-1.6** | 预设5个常用策略模板 | 提供「突破新高」「低位反弹」「强势股回调」等模板 |

#### 2.1.3 技术方案

**规则编辑器设计**：
```
┌─────────────────────────────────────────┐
│  策略名称：我的突破策略                  │
├─────────────────────────────────────────┤
│  IF (                                  │
│    [涨跌幅] > 3%                       │
│    AND                                 │
│    [成交量] > 昨日 × 1.5               │
│    AND                                 │
│    [换手率] > 5%                       │
│  ) THEN (                              │
│    加入策略池                          │
│    推送提醒（可选）                    │
│  )                                     │
├─────────────────────────────────────────┤
│  [保存策略] [预览结果] [回测]          │
└─────────────────────────────────────────┘
```

**预设模板**：
| 模板名称 | 核心逻辑 | 适用场景 |
|---------|---------|---------|
| 突破新高 | 价格创20日新高 + 放量 | 趋势突破 |
| 低位反弹 | 跌幅>15% + 缩量企稳 + 放量 | 超跌反弹 |
| 强势股回调 | 前期涨幅>20% + 回调5-10% | 强势股低吸 |
| 基本面优选 | 市盈率<30 + 营收增长>20% + 北向资金流入 | 价值投资 |

### 2.2 P1：策略回测

#### 2.2.1 功能描述

用历史数据验证自定义策略，展示策略表现。

#### 2.2.2 验收标准（AC）

| AC ID | 验收条件 | 测试方法 |
|-------|----------|----------|
| **AC-P3-2.1** | 支持选择回测周期（1/3/6/12个月） | 可选回测最近1个月到1年的数据 |
| **AC-P3-2.2** | 显示回测核心指标 | 收益率、最大回撤、胜率、夏普比率 |
| **AC-P3-2.3** | 可视化展示策略曲线 vs 大盘 | 图表对比策略与沪深300/上证指数 |
| **AC-P3-2.4** | 列出回测期间的交易记录 | 买入/卖出时间点、价格、收益率 |

#### 2.2.3 技术方案

**回测指标**：
```
收益率 = (期末净值 - 期初净值) / 期初净值 × 100%
最大回撤 = max((峰值 - 谷值) / 峰值) × 100%
胜率 = 盈利交易数 / 总交易数 × 100%
夏普比率 = (策略收益率 - 无风险利率) / 策略波动率
```

**数据来源**：
- AKShare历史行情数据
- 默认回测周期：从当前往前推1年

## 三、非功能需求

### 3.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 回测速度 | <10秒（1年数据） | 策略回测响应时间 |
| 规则匹配 | <5秒 | 策略池刷新速度 |

### 3.2 可用性要求

| 场景 | 处理方式 |
|------|----------|
| 回测失败 | 显示失败原因 + 重试按钮 |
| 规则语法错误 | 实时高亮错误位置 + 提示 |
| 社区内容加载失败 | 显示缓存数据 + 刷新按钮 |

#### 3.2.1 回测降级策略（详细）

**降级优先级**：
```
1. 缩短回测周期（1年→6个月→3个月→1个月）
2. 简化策略指标（夏普比率→仅收益率+胜率）
3. 单只股票回测→批量回测
4. 显示预设模板回测结果
```

**降级触发条件**：
| 条件 | 触发降级 |
|------|----------|
| 回测超时 > 10秒 | 自动缩短周期 |
| 历史数据不完整 | 提示"数据有限，结果仅供参考" |
| 计算错误 | 显示预设模板的参考回测结果 |

**用户提示文案**：
- "回测数据加载中...已自动缩短周期以提升速度"
- "部分历史数据不可用，结果仅供参考"
- "策略回测失败，您可以查看类似预设模板的历史表现"

## 六、后续固化建议

### 6.1 方案评审对齐机制（建议固化）

**对齐原则**：
1. 技术框架输出前，必须先做**前置调研**（数据源、技术栈等）
2. 技术框架对齐时，**不以技术细节提问**，而以**用户体验/产品价值提问**
3. 涉及**方案取舍**时，必须提供**利弊分析和充分理由**
4. 用户**确认框架决策**后，再细化技术方案

**评审检查清单**：
- [ ] 数据源是否充分调研？
- [ ] 技术方案能否实现产品需求？
- [ ] 用户体验指标是否可达？
- [ ] 扩展性路径是否清晰？
- [ ] 方案取舍是否有充分利弊分析？

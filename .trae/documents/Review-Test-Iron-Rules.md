## 铁律三：评审与测试流程

### 3.1 代码评审流程（强制顺序）

```
步骤1: 准备阶段
├── 读取 PRD.md 第13.2节（功能清单）
├── 读取 PRD.md 第14节（验收标准）
├── 读取 Technical-Architecture.md 第6节（模块设计）
└── 输出：《评审准备确认表》

步骤2: 代码检查
├── 检查项A：功能完整性（9项）
├── 检查项B：技术方案符合性（7项）
├── 检查项C：代码质量（5项）
├── 检查项D：安全合规（4项）
└── 输出：《代码评审检查表》（每项必须打勾）

步骤3: AC-4.3专项验证
├── 检查后端代码是否使用riskPreference参数
├── 检查评分公式是否包含风险偏好系数
├── 检查不同风险偏好是否产生不同结论
└── 输出：《AC-4.3验证报告》

步骤4: 评审结论
├── 所有检查项通过 → 批准合并
├── 任一检查项失败 → 拒绝合并，返回修改
└── 输出：《评审结论书》
```

### 3.2 QA测试流程（强制顺序）

```
步骤1: 准备阶段
├── 读取 Test-Plan.md 全文
├── 读取 PRD.md 第14节（验收标准）
├── 准备测试数据（600519, 688981, 300750）
└── 输出：《测试准备确认表》

步骤2: 冒烟测试
├── 执行TC-001至TC-009
├── 全部通过 → 继续
├── 任一失败 → 测试终止，返回开发
└── 输出：《冒烟测试报告》

步骤3: 功能测试
├── 执行TC-005至TC-019
├── 记录所有失败用例
└── 输出：《功能测试报告》

步骤4: UI/UX测试
├── 执行TC-020至TC-024
├── 必须在iOS Safari测试
├── 记录所有滚动/适配问题
└── 输出：《UI/UX测试报告》

步骤5: AC-4.3专项测试
├── 执行TC-AC43-001至TC-AC43-003
├── 验证同一股票在不同风险偏好下的结论差异
├── 差异不明显 → 测试失败
└── 输出：《AC-4.3专项测试报告》

步骤6: 测试结论
├── 所有P0用例通过 + AC-4.3通过 → 测试通过
├── 任一P0用例失败 或 AC-4.3失败 → 测试失败
└── 输出：《测试结论书》
```

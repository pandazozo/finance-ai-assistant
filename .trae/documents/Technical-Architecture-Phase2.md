## 三、LLM集成方案

### 3.1 LLM服务商选择

| 服务商 | 优点 | 缺点 | 推荐 |
|--------|------|------|------|
| **通义千问** | 中文理解好、成本低、阿里云生态 | 需要阿里云账号 | ✅ 首选 |
| GPT-4 | 能力最强 | 成本高、中文有时差 | ❌ 暂不考虑 |
| Claude | 长文本理解好 | 国内访问不便 | ❌ 暂不考虑 |

### 3.2 通义千问集成

**SDK选择**：`dashscope`（阿里云官方Python SDK）

**安装**：
```bash
pip install dashscope
```

**环境变量**：
```bash
export DASHSCOPE_API_KEY="your-api-key"
```

### 3.3 Prompt设计规范

```
【系统提示词】
你是一位专业的A股分析师，专注于短线交易机会发现。

【用户提示词模板】
股票：{stock_name}({stock_code})
行情：最新价{price}元，涨跌{change}%，成交{volume}万手
风险偏好：{risk_preference_label}

要求：
1. 结合行情和风险偏好生成分析
2. 100字以内，专业易懂
3. 包含具体建议

风险提示：市场有风险，投资需谨慎。AI分析仅供参考，不构成投资建议。
```


```json
  "source": "rule_engine",

}
```

## 四、资讯权重算法

### 4.1 算法设计

```
影响力评分 = 时效性得分 × 0.3 + 相关性得分 × 0.4 + 权威性得分 × 0.3
```

### 4.2 因子计算

**1. 时效性得分（0-100）**
```
发布<1小时: 100分
发布<3小时: 80分
发布<6小时: 60分
发布<12小时: 40分
发布<24小时: 20分
发布>24小时: 10分
```

**2. 相关性得分（0-100）**
```
资讯标题包含股票名称: +50分
资讯正文提及股票: +30分
资讯提及相关行业: +20分
```

**3. 权威性得分（0-100）**
```
官方媒体（上证报、中证报等）: 100分
主流财经媒体（证券时报、东方财富等）: 70分
自媒体: 30分
```

### 4.3 排序规则

```
高影响力（80+）: 🔥 标记，置顶
中影响力（50-79）: 正常显示
低影响力（<50）: 折叠显示或隐藏
```

## 五、数据流设计

### 5.1 股票分析数据流

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 股票代码     │ ──► │ 行情数据     │ ──► │ 资讯数据     │
│ (code)       │     │ (AKShare)    │     │ (权重计算)   │
└──────────────┘     └──────┬───────┘     └──────┬───────┘
                            │                    │
                            ▼                    ▼
                     ┌──────────────┐     ┌──────────────┐
                     │ 风险偏好     │     │ 影响评分     │
                     │ (用户配置)   │     │ (0-100)     │
                     └──────┬───────┘     └──────┬───────┘
                            │                    │
                            └────────┬───────────┘
                                     │
                                     ▼
                            ┌──────────────┐
                            │ LLM/规则引擎 │
                            │ (AI分析)     │
                            └──────┬───────┘
                                   │
                                   ▼
                            ┌──────────────┐
                            │ 统一响应     │
                            │ (前端展示)   │
                            └──────────────┘
```

### 5.2 缓存策略

| 数据类型 | 缓存时间 | 说明 |
|----------|----------|------|
| 股票行情 | 30秒 | 实时性要求高 |
| 资讯列表 | 5分钟 | 可接受延迟 |
| AI结论 | 不缓存 | 每次请求生成 |
| LLM响应 | 可选30秒 | 减少调用成本 |

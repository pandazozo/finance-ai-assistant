## 一、测试范围概述

### 1.1 测试对象

| 模块 | 页面 | 功能点 |
|------|------|--------|
| 首页 | HomePage | 行情展示、刷新、快速操作 |
| 自选股 | WatchlistPage | 添加、删除、搜索 |
| 个股详情 | StockDetailPage | AI结论、跳转交易 |

| 类型 | 说明 |

| **功能测试** | 每个按钮/功能的预期响应 |
| **流程测试** | 用户完整操作路径 |
| **边界测试** | 空数据、网络异常等边界情况 |
| **回归测试** | 修复后的Bug验证 |

### 2.7 AC-4.3专项测试（关键，必须执行）

> **对照文档**：PRD.md 第14.2节 AC-4.3
> **测试目的**：验证AI结论是否根据风险偏好不同而有差异

#### TC-AC43-001 激进型风险偏好

| 用例ID | TC-AC43-001 |
|--------|-------------|
| **功能** | 激进型风险偏好下的AI结论 |
| **前置条件** | 进入设置页，调整风险偏好 |
| **操作步骤** | 1. 设置高风险偏好比例：高风险80%/中风险15%/低风险5%<br>2. 保存配置<br>3. 进入任意股票详情页（如600519）<br>4. 记录AI结论等级 |
| **预期响应** | AI结论偏向积极，显示"强烈推荐"或"推荐" |
| **通过标准** | 同一股票在激进型下结论等级 ≥ 中性型下的结论等级 |

#### TC-AC43-002 保守型风险偏好

| 用例ID | TC-AC43-002 |
|--------|-------------|
| **功能** | 保守型风险偏好下的AI结论 |
| **前置条件** | 进入设置页，调整风险偏好 |
| **操作步骤** | 1. 设置低风险偏好比例：高风险10%/中风险30%/低风险60%<br>2. 保存配置<br>3. 进入同一股票详情页（如600519）<br>4. 记录AI结论等级 |
| **预期响应** | AI结论偏向谨慎，显示"谨慎"或"中性" |
| **通过标准** | 同一股票在保守型下结论等级 ≤ 中性型下的结论等级 |

#### TC-AC43-003 中性风险偏好

| 用例ID | TC-AC43-003 |
|--------|-------------|
| **功能** | 中性风险偏好下的AI结论 |
| **前置条件** | 进入设置页，调整风险偏好 |
| **操作步骤** | 1. 设置中风险偏好比例：高风险40%/中风险35%/低风险25%<br>2. 保存配置<br>3. 进入同一股票详情页（如600519）<br>4. 记录AI结论等级 |
| **预期响应** | AI结论为标准判断 |
| **通过标准** | 结论等级介于激进型和保守型之间 |

**AC-4.3测试通过标准**：
- 同一股票在三种风险偏好下的AI结论等级必须有明显差异
- 激进型结论等级 > 中性型结论等级 > 保守型结论等级（或相等，但不能相反）
- 若三种风险偏好下结论完全相同，则测试失败

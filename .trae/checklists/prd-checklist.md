# 产品经理 - PRD检查清单

## PRD基本信息
- [ ] 文档版本号与日期
- [ ] 变更记录
- [ ] 相关人员（需求提出者、产品负责人等）

## 需求描述
- [ ] 需求背景与目标明确
- [ ] 用户场景清晰
- [ ] 解决的问题明确
- [ ] 不做什么（范围界定）明确

## 功能需求
- [ ] 功能清单完整
- [ ] 每个功能有明确说明
- [ ] 功能优先级标记（P0/P1/P2）
- [ ] 功能之间的依赖关系清晰

## 验收标准
- [ ] 每个功能有可量化的验收标准
- [ ] 验收标准可测试
- [ ] 边界条件明确
- [ ] 异常情况处理说明

## 用户体验
- [ ] 考虑了移动端体验
- [ ] 操作流程简洁清晰
- [ ] 有错误提示与反馈机制
- [ ] 加载状态处理

## 非功能需求
- [ ] 性能指标（如响应时间）
- [ ] 安全要求
- [ ] 兼容性要求（浏览器、设备等）

## 附录
- [ ] 原型/设计稿链接
- [ ] 相关参考资料
- [ ] 开放问题列表

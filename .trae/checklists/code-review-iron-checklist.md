## AC-4.3专项验证（关键）

### 必须检查的代码位置

**文件**：`app.py`  
**函数**：`get_ai_conclusion` (第229-288行)

### 检查清单

| 检查点 | 检查内容 | 通过标准 |
|--------|----------|----------|
| AC43-001 | 函数是否接收riskPreference参数 | `request: AIConclusionRequest` 包含riskPreference |
| AC43-002 | 评分计算是否使用风险偏好系数 | 代码中包含类似 `score * risk_coefficient` 的计算 |
| AC43-003 | 风险偏好系数是否影响结论等级 | 不同系数导致不同的level/label输出 |
| AC43-004 | 激进型系数是否>1 | 高风险偏好系数 > 1.0 |
| AC43-005 | 保守型系数是否<1 | 低风险偏好系数 < 1.0 |

### 参考实现（Technical-Architecture 6.1.2节）

```python
# 风险偏好系数映射
risk_coefficients = {
    "high": 1.2,    # 激进型：放大正向信号
    "medium": 1.0,  # 中性型：标准
    "low": 0.8      # 保守型：放大风险信号
}

# 评分公式
final_score = base_score * risk_coefficient

# 结论映射
if final_score >= 80:
    level, label = 4, "强烈推荐"
elif final_score >= 60:
    level, label = 2, "推荐"
# ...
```

## 评审流程（强制顺序）

```
步骤1: 准备
├── 读取 PRD.md 第13.2节（功能清单）
├── 读取 PRD.md 第14节（验收标准）
├── 读取 Technical-Architecture.md 第6节（模块设计）
└── 输出：《评审准备确认表》

步骤2: 功能检查
├── 检查A-001至A-009（9项功能）
├── 重点验证A-005（AC-4.3）
└── 输出：《功能检查表》

步骤3: 技术检查  
├── 检查B-001至B-007（7项技术）
├── 重点验证B-006（风险偏好系数）
└── 输出：《技术检查表》

步骤4: AC-4.3专项
├── 检查AC43-001至AC43-005（5项）
├── 人工验证不同风险偏好下的结论差异
└── 输出：《AC-4.3验证报告》

步骤5: 质量检查
├── 检查C-001至C-005（代码质量）
├── 检查D-001至D-004（安全合规）
└── 输出：《质量检查表》

步骤6: 结论
├── 所有检查项通过 → 批准合并
├── 任一检查项失败 → 拒绝合并
└── 输出：《评审结论书》
```
